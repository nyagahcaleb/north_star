Telecom Engineer Portfolio - Multipage Version

Files:
- index.html — Home page (hero section)
- about.html — About page with skills and experience
- projects.html — Projects showcase page with add/upload form
- services.html — Services offered
- contact.html — Contact information
- assets/style-portfolio.css — Responsive styling
- assets/portfolio.js — Project management (add, delete, localStorage)

How it works:
1. Open index.html in your browser (this is the home page).
2. Navigate between pages using the top menu.
3. Go to "Projects" to add new projects via the "Add Project" button.
4. Projects are stored locally in browser's LocalStorage (no server required).

Customize:
- Edit each HTML file to update your name, email, phone, LinkedIn, and CV link.
- Add your profile picture by replacing the hero image URL.
- Modify skills, certifications, and services to match your profile.
